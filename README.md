# LD45 - Catch The Money

A game created during the 48-hour Ludum Dare 45 Game Jam as a two-person team (05.10.-07.10.2019).

The theme of the Game Jam was "Start with Nothing".

## 🛠 Tech Stack
Unity, C#

## My Tasks
- Game Design
- Game Programming
- Creating sound effects using the tool 'sfxr'

### 🎮 Game Design
- Starting with nothing and collecting money throughout the game
- Visual style and gameplay inspired by the classic game 'Moorhuhn schießen'
- Increasing difficulty with each level, e.g. money can be deducted again
